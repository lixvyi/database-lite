# 操作系统模块效果证据

测试环境为当前 Windows 机器、Python 标准库运行时。时间数据受机器负载影响，应重新运行而不是把本次数值当作固定性能承诺。

## 缓存效果

执行 `python3 benchmarks/os_benchmark.py`：

| 指标 | 实测 |
|---|---:|
| 首次冷读 | 11.71 ms |
| 随后 1000 次热读总耗时 | 7.12 ms |
| 1000 次热读新增磁盘读取 | 0 |
| 总命中/未命中 | 1000 / 1 |
| 命中率 | 99.90% |

这证明相同热点页驻留内存后，后续读取不再调用 PageFile。性能结论来自 I/O 次数，而非只依赖易波动的毫秒值。

## 有界并发队列效果

基准任务模拟 1000 个 1ms I/O 等待：

| 指标 | 实测 |
|---|---:|
| 串行完成 | 1557.52 ms |
| 8 worker 有界队列 | 193.54 ms |
| 加速比 | 8.05× |
| 最大队列深度 | 64/64 |
| 完成/失败/拒绝 | 1000/0/0 |

队列没有创建 1000 个线程，最大等待区严格限制为 64；提交方在满队列时阻塞形成背压。因此吞吐提升没有以无界内存增长为代价。

## 可靠性效果

- 写前屏障测试：WAL durable_lsn 落后时，脏页刷回抛出 `WriteBarrierError`。
- 崩溃测试：写入 WAL 后不调用 close/checkpoint，重新创建 StorageService；恢复器重放页面且内容一致。
- Checkpoint 测试：所有 dirty frame 清零，control.checkpoint_lsn 等于 WAL 最新持久 LSN。
- 页目录测试：释放 page 7 后下一次分配复用 page 7，offset 始终是 `7×4096`。
