## 指导书可选扩展：只选两项

| 选项 | 解析/语义 | 计划/执行 | 测试 |
|---|---|---|---|
| UPDATE | `Parser.update`、`UpdateStmt`、赋值类型检查 | Update → Filter → SeqScan；页内更新或迁移 RID | `test_update_and_order_by_ast`、`test_update_order_by_and_system_catalog` |
| ORDER BY | `order_opt`、列存在检查 | Project → Sort → Filter/SeqScan；稳定多键排序 | 同上 |

## 明确边界

- `pg_catalog` 可查询但只读，防止普通 DML 破坏元数据。
- DELETE 为逻辑删除；页内碎片压缩尚未实现。
- UPDATE 是语句级表写锁，不提供事务回滚或 MVCC。
- JOIN、GROUP BY、索引和代价优化不属于本次选做范围。
