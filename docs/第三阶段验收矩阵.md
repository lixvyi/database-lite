# 三份课程材料逐条验收矩阵

本矩阵以两份 PPT 和《大型平台软件设计实习》指导书为验收标准。示例代码只用于解释，不作为实现指令。基础要求必须完成；扩展按三个模块分别限制在两项以内。

## 明确边界

- DELETE 使用逻辑删除，页内压缩尚未实现。
- UPDATE 使用简单表级写锁，不提供事务回滚。
- ORDER BY 在内存中稳定排序，不实现外部排序。
- 图书借阅业务页面独立使用 SQLite，只作为上层演示；课程 MiniDB 验收使用 `/api/minidb/*` 和 `minidb_cli.py`。
