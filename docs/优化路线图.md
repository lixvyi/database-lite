# 优化计划与结构前后对比

## 已完成：编译期规则优化

```text
优化前                         优化后
Project[name]                  Project[name]
└─Filter[1=1 AND age>10+8]     └─Filter[age>18]
  └─SeqScan[student]             └─SeqScan[student]
```

规则框架目前包含常量折叠、布尔化简、恒真 Filter 消除，以及计划生成阶段的 `Project[*]` 冗余消除。`inspect()` 和 `EXPLAIN` 同时输出前后结构，便于验证语义等价。

## Token 与 Parser 优化计划（加分项）

| 当前 | 计划 | 可量化指标 |
|---|---|---|
| Token 全量列表 | 流式 TokenIterator，仅保留 lookahead | 10MB SQL 峰值内存 |
| 每次 uppercase 判断关键字 | ASCII 大小写无关哈希表 | tokens/s |
| 错误立即停止 | panic-mode 同步到 `;` | 多错误一次报告数 |
| AST 通用 dataclass | arena/节点编号与共享源码区间 | 节点内存、序列化大小 |

## 存储结构演进

```text
当前：Catalog → heap page chain → SeqScan
阶段1：Catalog → heap page chain + free-space map
阶段2：Catalog → heap + B+Tree(index file) → IndexScan
阶段3：统计信息 → Cost Optimizer → SeqScan / IndexScan / Join 顺序
```

free-space map 避免插入时扫描所有页；B+Tree 把等值定位从 O(N) 降到 O(log N + K)；统计信息保存行数、不同值数、NULL 比例和直方图，为简单代价模型提供输入。

## 并发与恢复演进

| 层次 | 当前结构 | 下一结构 | 边界变化 |
|---|---|---|---|
| 锁 | 表级 RWLock | 行级严格 2PL | 并发写不同 RID |
| 死锁 | 未形成跨表事务 | wait-for graph 检测 | 可安全支持多表事务 |
| 原子性 | 单语句内存路径 | WAL + BEGIN/COMMIT/ROLLBACK | 崩溃后 redo/undo |
| 隔离性 | 单表操作隔离 | MVCC 快照 | 读不阻塞写 |
| 缓存 | LRU | LRU-K / Clock | 顺序扫描不污染热点 |

## 查询优化扩展

1. Projection pruning 把所需列集合下推至扫描算子。
2. Predicate pushdown 把可下推条件移到 JOIN 两侧。
3. 等价规则使用固定点迭代，但设置轮数上限避免规则震荡。
4. 增加 `EXPLAIN ANALYZE`，同时输出估算行数、实际行数、耗时、page hit/miss。
5. 对每条优化建立结果等价性测试与反例测试，不能只比较运行速度。
