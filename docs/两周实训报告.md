# 图书借阅数据库系统实训报告

## 一、实训目标

在两周内完成一个可启动、可演示的关系型数据库应用，掌握需求分析、概念结构设计、逻辑结构设计、SQL 建表、约束与索引、后端接口、前端交互和软件测试的完整流程。

## 二、需求分析

图书室管理员需要维护馆藏和读者资料，并完成借书、还书和记录查询。系统的关键规则是：无库存时不能借出、停用读者不能借书、一本书归还后库存必须恢复、历史借阅记录不得因基础资料误删而丢失。

## 三、总体设计

系统采用浏览器/服务器结构。浏览器负责表格展示、搜索和表单交互；Python HTTP 服务负责路由、参数校验与业务事务；SQLite 负责持久化。该架构无需额外安装数据库服务，适合机房演示，同时保留完整 SQL 文件便于答辩。

## 五、关键实现

借阅时先查询图书库存与读者状态，通过后在同一数据库事务中减少 `available_copies` 并插入借阅记录。归还时更新借阅状态和归还日期，同时恢复库存。任一 SQL 失败会自动回滚，从而避免“有借阅记录但库存未减少”等不一致状态。

## 六、测试结果

自动测试使用独立临时数据库验证统计、新增、借出和归还。手工测试重点验证导航、搜索、表单校验、重复编号提示、逾期展示和浏览器刷新后的数据持久化。

## 七、总结与展望

本项目实现了从数据库设计到可用界面的闭环，覆盖关系模型、约束、索引、连接查询、聚合查询和事务等课程重点。后续可以增加登录与权限、预约、罚金、数据导出、操作日志和分页，但这些功能不属于本次两周实训的核心范围。
