# 第三阶段答辩逐文件导读

答辩顺序建议固定为“入口 → 编译 → 计划 → 执行 → 行页 → 缓存/WAL → 文件”，随机抽到任一函数时先说明输入、输出、状态变化和失败条件。

## 入口与编译器

- `minidb/engine.py`：`Database.execute` 对每条语句依次做语义分析、建计划、优化和执行；最后 flush。`inspect` 只编译不改数据，并输出 Token、AST、语义通过标记和优化前后计划。
- `tokens.py`：`KEYWORDS` 决定关键字与普通标识符的边界；Token 保存 type、lexeme、location、value。
- `lexer.py`：唯一字符游标维护行列号；字符串分支处理 SQL 双单引号转义；非法字符立即抛 LexicalError。
- `ast.py`：节点只表达语法结构。`inferred_type` 在语义阶段回填，不承担读写。
- `parser.py`：`match` 是可选消费，`expect` 是必须消费。表达式函数的调用层级体现优先级。`update` 构造赋值列表，`select` 构造排序键。
- `semantic.py`：先绑定表列，再递归推导表达式类型；UPDATE 同时检查目标列和右侧表达式；`pg_catalog` 只允许 SELECT。

## 目录、计划与执行

- `catalog.py/PagedCatalog._ensure_page`：首次启动分配页 0；已有库必须能找到保留页 0。
- `PagedCatalog.save/load`：每列编码为一条目录记录，放入从页 0 开始的 `SYP1` 槽页链；目录超过一页会自动扩展，`rows` 把内部模式转成可查询的特殊表行。
- `plan.py`：每条语句只生成算子树，不执行。SELECT 的构造顺序为 SeqScan → Filter → Sort → Project。
- `optimizer.py`：先 deepcopy 保留优化前证据，再做常量折叠、布尔化简、恒真 Filter 消除。
- `execution.py/Executor.run`：DDL/DML 使用表写锁，普通查询使用表读锁；返回影响行数或结果集。
- `Executor._rows`：SeqScan 产生 `(RID,row)`；Filter 决定是否继续；Sort 物化并稳定排序；Project 生成新行字典。
- `TableHeap`：隐藏表页链。insert 找空间或分配新页；scan 跟随 next_page；delete 写 tombstone；update 优先原槽，否则迁移记录。

## 行、页与 OS 仿真实体

- `storage/record.py`：encode/decode 必须互逆；NULL bitmap 决定字段体中是否存在该字段；VARCHAR 先写 UTF-8 字节长度。
- `storage/page.py`：Header 维护页号、槽数、空闲区和下一页；Slot 提供间接寻址；记录体从页尾反向增长。
- `storage/os_adapter.py`：把原始 4096 字节包装为 SlottedPage；上下文退出时只把 dirty 页交给 StorageService。
- `os_sim/interfaces.py`：PageStore 是数据库与 OS 的契约，替换缓存算法不会改变上层。
- `os_sim/cache.py`：fetch 处理 hit/miss/pin；update 先写 WAL；`_evict` 只选未 pin frame，dirty victim 先刷。
- `os_sim/wal.py`：每条 JSON 日志含 LSN、page_id、generation、after-image、CRC；append 后 flush+fsync。
- `os_sim/page_file.py`：`page_id×4096` 是唯一物理偏移公式；双控制文件用临时文件原子替换；CRC 检测破坏。
- `os_sim/service.py`：组合文件、缓存、WAL 和恢复；`checkpoint` 先刷页再推进 LSN。

## 高频追问答案

1. 为什么目录放页 0？固定入口便于启动，无需先读取另一个目录文件；它仍通过同一页服务和 WAL。
2. 为什么不用 mmap？课程要观察 dirty、刷回和 WAL 障碍，mmap 会隐藏关键时机。
3. 为什么先 Sort 后 Project？排序列可以不在 SELECT 输出中，投影太早会丢失排序键。
4. 为什么 UPDATE 基于原行算所有赋值？避免赋值顺序改变后一个表达式的含义。
5. 断电为何不丢已记录页？WAL fsync 先于数据页；重启按 generation 重放。
6. 当前事务边界是什么？表级读写互斥与页级 redo；没有 rollback、MVCC 或多语句原子提交。
