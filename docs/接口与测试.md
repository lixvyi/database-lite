# 接口与测试说明

## HTTP 接口

| 方法 | 地址 | 作用 |
|---|---|---|
| GET | `/api/dashboard` | 总览统计与最近借阅 |
| GET | `/api/books?q=` | 查询图书 |
| POST | `/api/books` | 新增图书 |
| GET | `/api/readers?q=` | 查询读者 |
| POST | `/api/readers` | 新增读者 |
| GET | `/api/loans?q=` | 查询借阅记录 |
| POST | `/api/loans` | 办理借阅 |
| PUT | `/api/loans/{id}/return` | 办理归还 |
| GET | `/api/minidb/status` | 系统目录、页目录与缓存/WAL 指标 |
| POST | `/api/minidb/inspect` | 编译 SQL，返回 Token、AST、优化前后计划 |
| POST | `/api/minidb/execute` | 执行 SQL，返回结果、页与目录状态 |
| GET | `/api/os/status` | OS 仿真实体状态、frame 与事件 |
| POST | `/api/os/action` | 分配页、写页、checkpoint |

接口统一使用 JSON。业务冲突返回 409，缺少参数返回 400，不存在返回 404。

## 自动测试

`tests/test_api.py` 使用临时 SQLite 数据库启动真实 HTTP 服务，覆盖：

1. 总览统计接口；
2. 新增图书；
3. 借出后库存减一；
4. 归还后库存恢复。

MiniDB 与 OS 的核心正确性由 `tests/test_minidb.py`、`tests/test_os_sim.py` 覆盖；第三阶段完整场景见《第三阶段测试报告》。

## 手工验收

1. 启动后四个导航页面均可切换。
2. 新增图书、读者后列表立即出现记录。
3. 办理借阅后总览借阅数增加、可借数减少。
4. 点击归还后状态变为已归还，库存恢复。
5. 对逾期记录显示“已逾期”。
6. 重复 ISBN 或读者证时给出明确错误提示。
